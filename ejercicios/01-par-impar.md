# Ejercicio 1: Par o impar 

## Problema
Determinar si un número entero es par o impar. 
## Entrada
Un número entero. 
## Proceso
Inicio
  Leer número 
Si número MOD 2 = 0 Entoces 
  Escribir "Par"
SiNo
  Escribir "Impar" 
 FinSi
Fin
## Salida 
Indicar si el número es par o impar. 
## Pruebas 
| Entrada | Resultado esperado | 
|---------|--------------------| 
| 8       | Par                | 
| 7       | Impar              | 
| 0       | Par                |
| -6      | Par
